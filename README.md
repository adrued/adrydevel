### ⌬ &nbsp; What I build

I ship autonomous trading systems and on-chain agent infrastructure — agent swarms, verifiable reasoning, and tokenized-asset trading on Robinhood Chain. Reasoning runs on open-weights (Nous Research Hermes). Most of it ends up open source.

### ⌬ &nbsp; Building

| Repo | What it does | Stack |
|------|--------------|-------|
| **[bastion](https://github.com/adrydevel/bastion)** | Autonomous, verifiable AI fund — a swarm of agents trades tokenized stocks and proves every trade on-chain | TypeScript |
| **[robinhood-chain-mcp](https://github.com/adrydevel/robinhood-chain-mcp)** | MCP server — typed tools that let any agent read Stock Tokens and place swaps | TypeScript |
| **[robinhood-chain-sdk](https://github.com/adrydevel/robinhood-chain-sdk)** | Typed client — Stock Tokens, oracle NAV, swaps | TypeScript |
| **[bastion-rs](https://github.com/adrydevel/bastion-rs)** | Rust port of the agent core — small single binary | Rust |
| **[awesome-robinhood-chain](https://github.com/adrydevel/awesome-robinhood-chain)** | Curated ecosystem list for Robinhood Chain | Markdown |

### ⌬ &nbsp; Build surface

```text
Agents   ·  swarm councils, quorum voting, Hermes-native routing
Trading  ·  Kelly/CVaR risk kernels, regime detection, execution
Chain    ·  Robinhood Chain (viem), tokenized stocks, on-chain proofs
Proof    ·  keccak256 attestation, provenance trails
```

### ⌬ &nbsp; What I believe

> **Auditable beats autonomous** — an agent that cannot show its evidence trail is a demo, not infrastructure.
>
> **Consensus over conviction** — no single agent moves capital; a quorum does, or the desk stays flat.
>
> **Non-custodial or nothing** — keys stay on your machine, the chain stays the source of truth.
